# FG-08 Embedded Sheet

SHEET-A1-31CF

Insert one embedded Feishu Sheet with:

- columns `ID`, `Description`, `Quantity`, `Formula`
- at least 12 rows and 12 columns so horizontal width is exercised
- one merged region spanning two rows and two columns
- Unicode value `表格 Ω 行`
- formula `=SUM(C2:C4)`

Final sentinel: SHEET-END-911B
